## Overview

The Radio component provides a customizable radio button with support for labels, different sizes, colors, and states.
It can be used in both controlled and uncontrolled modes.

> **Important:** Radio should be used in combination with the RadioGroup component as demonstrated in [these examples](?path=/docs/components-inputs-radiogroup--docs).

### Tips
By default, click on the label (even custom ones) toggle the value of the radio input.
In order to prevent this behavior, you need to prevent the default on the click event of the label itself.
