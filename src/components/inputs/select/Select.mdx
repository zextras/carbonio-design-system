Select element maintains the same behavior of the [standard select element](https://www.w3.org/TR/2011/WD-html5-author-20110809/the-select-element.html).
The dropdown menu and the items are rendered like the Dropdown component.

The component supports both **controlled** and **uncontrolled** modes, as well as **single** and **multiple** selection.
