Dropdowns are toggleable, contextual overlays for displaying lists of links and more.
They’re toggled by clicking.

Dropdown list items can be customized with components and and can be disabled.
Disabled items has a tooltip which content can be configured with the _tooltipLabel_ prop of the item.

<Primary />

<Controls />


## Keep open

The `keepOpen` item property can be used to block the automatic closure of the dropdown on clicking the item.
This allows a finer control of the dropdown in mixed behavior cases.

<Canvas of={DropdownStories.KeepOpen} />

## Force open

Force open prop can be used to create a controlled dropdown.
If dropdown should be opened with single click, just value the outside state with the onOpen and onClose callbacks.
If dropdown should not be opened with single click, but only from outside,
then the dropdown must be set as disabled, to disable the click callback on the children element.
