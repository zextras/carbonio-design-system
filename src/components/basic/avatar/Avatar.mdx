The Avatar component is a representation of another user.

It is a container that can either contain a user's profile picture or its capitals, and it can have three sizes.
Default shape is round, but it can be changed with the `shape` prop.

## With Capitals

### Letters

The capital letters are calculated as follows:

1. The special characters are removed.
2. If the label is only one or two characters long, it's directly used as capitals.
3. If the label is a single word the result is `first letter + last letter`.
4. Otherwise, the result is `first letter of the first word + first letter of the last word`.
5. The remaining corner cases are handled by displaying a fallback icon.

<Canvas of={AvatarStories.Label} />

### Background

The background color is calculated by getting the remainder of the integer division between the sum of the charCodes of the label string and the amount of colors available in the avatar color palette.
This value is then used as an index for the said palette.

It can also be forced to a theme palette value by using the `background` prop.
